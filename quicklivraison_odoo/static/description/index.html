Quick Livraison Connector for Odoo 18

Create Quick Livraison parcels directly from Odoo sales orders, print shipping labels, synchronize delivery statuses, and follow every shipment from one place.

Main features

Create parcels

Send customer, address, city, amount, product, and order information from a confirmed sales order.

Print labels

Download and print the Quick Livraison shipping label from the Odoo sales order.

Track delivery

Synchronize tracking status manually or automatically with the included scheduled action.

Configuration

  1. Install the module and open Settings > Sales > Quick Livraison.
  2. Enter the API base URL and the API key supplied by Quick Livraison.
  3. Test the connection and synchronize the supported delivery cities.
  4. Open a confirmed sales order and choose Create Quick Livraison Parcel.
